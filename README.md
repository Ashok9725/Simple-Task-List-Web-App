# Simple-Task-List-Web-App
A simple and interactive **Task List Web Application** built using **HTML, CSS, and JavaScript**.  
This project allows users to add their own tasks dynamically and displays them using JavaScript loops.

---

## 🎯 **Project Objective**

The main goal of this project is to understand and demonstrate the use of:
- **Arrays** in JavaScript to store user-generated data.
- **For Loops** to iterate over tasks and display them dynamically.
- **While Loops** to continuously update the displayed list whenever new tasks are added.
- **DOM Manipulation** for rendering elements dynamically on the web page.

---

## 🚀 **Features**

✅ Add new tasks dynamically  
✅ Display all tasks using a **for loop**  
✅ Update the list using a **while loop**  
✅ Responsive and colorful UI design  
✅ Simple and beginner-friendly code  

---

## 🧩 **Technologies Used**

| Technology | Purpose |
|-------------|----------|
| **HTML5** | Structure of the web page |
| **CSS3** | Styling and layout |
| **JavaScript (ES6)** | Logic, loops, and dynamic updates |

---

## 🛠️ **How It Works**

1. The user enters a task in the input field.  
2. On clicking **Add Task**, the task is added to an array (`tasks`).  
3. The **for loop** iterates through this array and displays each task in the list.  
4. A **while loop** ensures that the list updates automatically when new tasks are added.  

---

## 🖼️ **Preview**

When you open `index.html` in your browser, you’ll see:
- A centered box with a colorful background.
- A text field to enter tasks.
- An “Add Task” button.
- A list that updates dynamically as you add new tasks.
